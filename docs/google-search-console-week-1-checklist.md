# Google Search Console Week 1 Checklist

Use this internal checklist after deployment. Do not simulate indexing from code. Open Google Search Console, use URL Inspection, then request indexing manually where appropriate.

## Manual Checks For Each URL

- Test Live URL.
- Confirm the page is indexable.
- Confirm the canonical URL is correct.
- Confirm no `noindex` tag exists.
- Confirm the title and meta description match the page topic.
- Request Indexing.
- Recheck after Google recrawls.
