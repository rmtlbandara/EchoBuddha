# Hosted browser setup correction — November 11, 2026

PR103's hosted release validation passed on df687e45a1d8572e8a37753173fed8d300d76b22. Its browser setup stalled twice before any browser test ran. Both observed Ubuntu26.04 runners failed DNS resolution for azure.archive.ubuntu.com, archive.ubuntu.com and security.ubuntu.com while Playwright installed OS packages. Microsoft package access and npm installation succeeded. This establishes the observed package-mirror failure, not a diagnosis of a global GitHub or Ubuntu outage.

[Attempt1](https://github.com/rmtlbandara/EchoBuddha/actions/runs/43034023992/job/130568560706) was cancelled after observing repeated DNS errors. A bounded retry on a fresh hosted runner, [attempt2](https://github.com/rmtlbandara/EchoBuddha/actions/runs/43034023992/job/130573956329), reproduced the failure and was also cancelled. Neither attempt is described as passing browser tests. Their history remains visible.

This focused correction pins only the browser-validation job to ubuntu-24.04 and installs the isolated Playwright Chromium without repeating APT installation of OS libraries already supplied by the hosted browser image. Installation is capped at five minutes. The browser executable still comes from the locked Playwright package and must launch and pass every existing consent, accessibility, tool, search, question and guide check. Missing libraries or a browser download failure still fail the job. No check, security permission or environment protection is waived.

The runner vendor documents Ubuntu24.04 as an available named image, including GoogleChrome, Chromium and their runtime environment. Playwright lists Ubuntu24.04 among supported platforms. Pinning a named image avoids an unreviewed major OS-label migration; it does not freeze weekly security updates or promise network immunity. [GitHub image policy](https://github.com/actions/runner-images#available-images) · [Ubuntu24.04 software](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md) · [Playwright requirements](https://playwright.dev/docs/intro#system-requirements)

The production workflow, exact-SHA guard, immutable artifact verification, release-identity retry, IndexNow ordering and monitoring implementation are unchanged. This is not a website deployment. Hosted validation for this correction and for the final content candidate must actually complete before either is treated as validated.
