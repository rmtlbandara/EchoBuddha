# Phase 8 Owner And Account Checklist

This checklist cannot be completed from the repository. It is for the site owner before any AdSense application or ad activation.

## AdSense Account

- [ ] Confirm AdSense account eligibility for the owner/entity and country.
- [ ] Confirm AdSense account identity, payments profile, tax information, and address requirements.
- [ ] Confirm there are no unresolved AdSense Policy Center issues.
- [ ] Confirm `echobuddha.com` ownership is verified in the relevant Google account.
- [ ] Decide whether the first submission is for the root domain only or includes any subdomain/property details.

## Search Console

- [ ] Confirm the production property is verified.
- [ ] Confirm latest deployed commit SHA and deployment timestamp.
- [ ] Confirm sitemap submission status for `https://echobuddha.com/sitemap.xml`.
- [ ] Review Page Indexing coverage.
- [ ] Review Manual Actions.
- [ ] Review Security Issues.
- [ ] Inspect priority URLs from Phases 1, 4, and 5.
- [ ] Export a fresh post-deployment GSC data set after at least 14-28 complete days.

## Analytics And Consent

- [ ] Review landing-page, country, device, and engagement reports.
- [ ] Confirm analytics behavior matches the Privacy Policy and owner preference.
- [ ] Confirm advertising consent is not assumed.
- [ ] Decide whether AdSense will use personalized ads, non-personalized ads, region-specific behavior, or no ads in regulated regions.
- [ ] Complete legal/privacy review for EEA, UK, and Switzerland traffic.
- [ ] Select and configure a Google-certified CMP if serving personalized ads where Google requires one.
- [ ] Add a consent revocation path if required by the chosen ad/CMP strategy.

## Legal, Copyright, Source, And Safety

- [ ] Review Privacy Policy, Terms of Use, Disclaimer, Editorial Policy, Corrections, Quote Attribution Policy, Buddhist Sources and Citations, and Meditation Safety.
- [ ] Complete copyright review for Dhammapada, sutta, translation, and quoted material.
- [ ] Complete Buddhist source/translation review if the owner wants stronger doctrinal confidence.
- [ ] Complete safety/clinical review before monetizing meditation or wellbeing-sensitive areas.
- [ ] Confirm no page claims legal, clinical, Buddhist-studies, or expert approval without evidence.

## Ad Placement Decisions

- [ ] Decide whether to use Auto Ads or manual ad units. Phase 8 recommends manual units only at first.
- [ ] Keep ads off search, 404, tools, trust/policy pages, today's reflection, and quote stories.
- [ ] Keep ads off meditation instructions and away from meditation safety notes.
- [ ] Keep ads away from quote text, quote cards, attribution disclosures, buttons, tool controls, navigation, images, and first-screen identity content.
- [ ] Approve exact first placement candidates and maximum density.
- [ ] Document QA rules: never click live ads, never ask others to click, never artificially refresh pages.
- [ ] Run a final production recheck after any ad/CMP implementation and before applying or requesting review.

## Owner Gate

Phase 8 repository evidence is strong enough for owner AdSense review. It is not enough by itself to apply for AdSense or activate ads. Application readiness requires the owner/account/legal/CMP/Search Console checks above.
