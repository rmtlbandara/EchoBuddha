# Echo Buddha Content Differentiation Governance

Effective: 2026-08-24

## Governing principle

Template controls presentation. Editorial judgment controls substance. Reusable UI, navigation, accessibility, authorship, correction, source-method and safety components are encouraged; reusable substantive prose is limited.

## Independent purpose

Every proposed indexable page must satisfy a user need that is not already adequately owned by another current page. A page is not approved merely because a template, keyword variation, dataset row or generator can produce it.

## Optional structure

Takeaways, examples, practice prompts, reflection questions, FAQs, conclusions and related-content blocks are optional unless the page family genuinely requires them. Empty optional fields are preferable to generic filler. Dictionary entries may use a stable reference structure; recurring reflections may use a stable product structure; neither exception authorizes interchangeable prose.

## Pre-publication review

Before publication, record and answer:

1. Does the page have an independent direct-user purpose?
2. Is its structure appropriate to that purpose?
3. Does it repeat a long substantive paragraph, introduction or conclusion from another page?
4. Are examples, practices and questions specific to this subject?
5. Are optional fields present because they help, or only because the template exposes them?
6. Does an existing canonical owner already satisfy the need?
7. Would the page still be worth publishing without Search traffic or advertising?

## Automation and batch publishing

Automation may validate schemas, metadata, links, duplication and editorial scaffolding. It may not independently draft, approve and publish a large indexable batch. Bulk work requires page-level purpose, source, similarity, safety and final-wording review under the responsible publisher identity.

## Similarity controls

Release validation checks duplicate titles, descriptions, long paragraphs, introductions, conclusions and suspicious universal section patterns. Natural terminology, quotations, safety text, source identifiers and reviewed UI/trust exceptions are not treated as failures solely because they repeat.

## Search and recovery safeguards

Content differentiation does not authorize URL, canonical, indexability, title, H1 or primary-intent changes. P0/P1 resources, Phase 5 quote governance, Phase 6 information gain and Phase 7 trust architecture remain protected unless a later separately authorized phase changes them.
