## Reflections: model, precision and timing

Several use both a “next step” and a similar practice instruction; that is optional tightening for a future edit, not a reason to turn them into longer generic articles. Retain noindex and the finite archive.

Three targeted repairs were implemented in the authorized sources:

1. **UTC accuracy.** The hub FAQ said selection used “the date in your browser”; `today.astro` and the selection helper use UTC. The FAQ now says “the current UTC day, calculated in your browser.” The utility correctly already described UTC. This is a disclosure correction, not a change to selection behavior.
2. **Metta/karuna precision.** `/daily-reflections/metta-for-a-difficult-person/` described loving-kindness as wishing freedom from suffering. Shared data now describes metta as wishing welfare and happiness, distinguishes compassion's response to suffering, and preserves the boundary/safety context. This follows the happiness/goodwill framing of the [Karaniya Metta Sutta translation](https://www.accesstoinsight.org/tipitaka/kn/snp/snp.1.08.than.html); the edit is original explanation, not copied translation.
3. **Speech summary boundary.** `/daily-reflections/speech-can-reduce-suffering/` presented true/useful/timely/kind as a direct definition. Shared data now calls it a modern practice reminder, names the traditional abstentions, links the existing fuller guide and notes that a needed truth can be uncomfortable. [SN 45.8](https://www.accesstoinsight.org/tipitaka/sn/sn45/sn45.008.than.html) and [MN 58](https://www.accesstoinsight.org/tipitaka/mn/mn.058.than.html) support the distinction. This avoids treating agreeable delivery as the only test for truthful beneficial speech.

Because meanings are shared, the latter two repairs also reach the hub, Today, tools and any reused reflection card. No new publication date was added for these small corrections.

The dependent-origination reflection is a modest original prompt about conditions, linked to deeper explanation. It should remain an entry point, not a replacement for the full Buddhist teaching. No broader doctrinal rewrite was justified from its short prompt alone.
