# November 1 publishing baseline

This recovery publishes no November article batch. Subsequent work must follow docs/publishing.md, CONTRIBUTING.md, the canonical SEO/content and CI/deployment governance, and docs/measurement-interventions.md.

Before a new page: state the reader need and distinct contribution, compare existing owners/support pages, verify specific source claims and translation boundaries, and complete the existing indexable-page approval record. Prefer improving an existing answer when it serves the same need.

Publish original explanation or useful application without rotating generic filler, misleading freshness, unsupported doctrinal claims, medical promises, fabricated credentials, or unverified rights assurances. Concise quote permalinks require explicit quote-specific applications, not an index-based generator. Keep original writing, paraphrase, text, commentary, tradition, history, and fiction distinct. Use relevant reading paths rather than latest-by-category links.

Review source accuracy, reader value, language/repetition, intent/metadata/links, and safety/publication readiness. The 0–4 rubric is internal judgment. Automated checks identify objective failures and review signals; noindex, a source link, or a green command cannot certify content quality.

Use truthful publication/modification dates, accessible headings, intact privacy/safety boundaries, current full release and browser checks, final-head hosted CI, and the exact-current-main single-artifact release workflow. Keep ads disabled and do not request AdSense review under this publishing baseline.

Record material releases and affected URLs in the existing intervention register. Preserve historical datasets; exclude the actual deployment day and derive the next complete 28 Pacific-day observation window with the existing finalization buffer. New November content can intervene again, so do not promise a clean causal comparison through ongoing material publishing.
