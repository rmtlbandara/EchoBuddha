# Q8 and Q9 semantic red team

Date: 2026-11-01

## Q8 attacks

| Attack | Required boundary | Result |
|---|---|---|
| “The Kathāvatthu proves universal agreement.” | Silence in one selected polemical corpus cannot establish every Buddhist opinion. | PASS |
| “The Kathāvatthu never mentions shrines or reverence.” | Direct search found `cetiya` and homage/circumambulation language; the narrower finding is that image veneration is not itself the controverted point. | PASS |
| “No images existed in the third century BCE.” | Earlier absence cannot be proven; chronology only limits the argument from silence. | PASS |
| “Later commentaries prove every Theravādin approved.” | They support normalization in the represented commentarial milieu, not unanimity. | PASS |
| “Wide practice equals universal doctrine.” | The page states broad adoption and rejects an all-places/all-periods inference. | PASS |
| “Q8 duplicates Q1 or Q7.” | Q8 owns historical consensus; Q1 owns command; Q7 owns chronology. | PASS |

## Q9 attacks

| Attack | Required boundary | Result |
|---|---|---|
| “Relics always give the most merit.” | Relics receive first ceremonial precedence in the cited Sri Lankan practice; this is not a guaranteed karmic result. | PASS |
| “All three always give exactly equal merit.” | The sources do not support that reverse absolute either. | PASS |
| “Merit is stored in the object.” | Objects carry meaning and different connections, but the page rejects a material points model. | PASS |
| “AN 6.63 directly ranks cetiyas.” | It supports intention as central to kamma and is explicitly bounded from cetiya ranking. | PASS |
| “AN 6.37 directly ranks cetiyas.” | It concerns giving to recipients; the page uses it only for donor/recipient factors and immeasurable merit. | PASS |
| “Sri Lankan temple order is universal Buddhism.” | The cultural and practice scope is named each time the order is asserted. | PASS |
| “A statue or tree is literally a living recipient.” | The page uses devotional reference directed toward the Buddha, not literal recipient identity. | PASS |

## Language and humanization review

The pages were read aloud during editorial review for sentence rhythm, repeated transitions, and unnatural source-led phrasing. Long source quotations were avoided. QuillBot and other paraphrase tools were not used. No personal experience, monastic review, scholarly endorsement, or AI-detection score is claimed.
