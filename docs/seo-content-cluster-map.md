# Echo Buddha SEO Content Cluster Map

This map keeps Echo Buddha organized around clear pillar pages and narrower supporting pages. Use it before adding or rewriting content so new pages do not target the same search intent as an existing guide.

## Core Rule

- Primary pillar pages should answer the broad beginner search intent.
- Supporting pages should target a narrower practical, reflective, script-based, question-based, or daily-life angle.
- Supporting pages should link up to the pillar. Pillars should link down only to the strongest support pages.
- Do not use canonical tags unless two URLs are truly duplicate or near-duplicate.
- Prefer rewriting title, H1, intro, and internal links before deleting or redirecting pages.
