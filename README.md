# Echo Buddha

Echo Buddha is a fast, static Astro website for Buddhist-inspired wisdom, original quotes, articles, meditation guidance, and educational content.

## Tech Stack

- Astro static output
- HTML, CSS, and TypeScript
- No UI framework dependency
- Hand-authored sitemap and robots routes

## Setup

```bash
npm install
npm run dev
```

The local dev server usually runs at `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```

The production static output is generated in `dist/`.

## Content

Shared content lives in `src/data/site.ts`.

- `quotes` contains 10 original quote entries.
- `articles` contains 6 article cards.
- The first 3 articles include full sample article content and are rendered by `src/pages/articles/[slug].astro`.

## SEO Notes

Each page uses the shared layout and SEO component for:

- Unique page titles and meta descriptions
- Canonical URLs
- Open Graph metadata
- Twitter card metadata
- JSON-LD for the website, organization, blog, and blog posting pages
- Semantic page structure and heading hierarchy

Static SEO files are generated by:

- `src/pages/sitemap.xml.ts`
- `src/pages/robots.txt.ts`

Update `SITE.url` in `src/data/site.ts` and `site` in `astro.config.mjs` before deploying to a different domain.

## AdSense Preparation

Ad-ready slots use `src/components/AdSlot.astro`. No Google AdSense publisher ID or ad-serving code is included.
Add approved ad code only after a real publisher ID is available and consent requirements have been reviewed.

## Deployment

This project can be deployed to static hosts such as Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any server that can host the `dist/` folder.

### Cloudflare Workers Static Assets

This website is fully static and deploys through Cloudflare Workers Static Assets. It does not require a Worker script, Pages Functions, SSR, or the `@astrojs/cloudflare` adapter.

Build and deploy:

```bash
npm run build
npx wrangler deploy
```

Wrangler uploads the generated `dist/` directory defined in `wrangler.jsonc`. The Astro configuration remains static with `output: "static"`.

## Maintenance

- Keep content original and respectful.
- Avoid copyrighted Buddhist images or copied passages.
- Add new full articles by adding content to `src/data/site.ts`.
- Review privacy, terms, disclaimer, and consent requirements before enabling new third-party services.
